Figure 5. Backbone-specific changes in held-out test AUROC relative to raw input for all four lung preprocessing conditions within each acquisition view. Differences are shown for MedSAM3 masking, MedSAM3 cropping, CheXMask masking, and CheXMask cropping, with pointwise 95% percentile confidence intervals from 20,000 paired subject-level cluster bootstrap replicates. These confidence intervals are not adjusted for multiplicity; Holm-adjusted p-values for all 56 comparisons are presented in Table 4. Positive ΔAUROC values indicate higher AUROC than the corresponding raw-input model, whereas negative values indicate lower AUROC.
