Figure 5. Backbone-specific changes in held-out test AUROC relative to raw input for all four lung preprocessing conditions within each acquisition view. (A) AP view. (B) PA view. Differences are shown for MedSAM3 masking, MedSAM3 cropping, CheXMask masking, and CheXMask cropping. Positive $\Delta$AUROC indicates higher discrimination than the matched raw-input model. Error bars represent paired subject-level cluster-bootstrap 95% confidence intervals based on 20,000 replicates and are shown to convey effect size and uncertainty only. Multiplicity-adjusted statistical inference is reported separately using Holm-adjusted $p$ values in Table 4.
